# 06 — Incident Response

## Objective

Investigate the Level 10 Wazuh alert generated by the custom brute-force correlation rule and document the incident using a practical SOC investigation workflow.

The investigation focused on determining whether the repeated failed authentication activity represented a real compromise or suspicious behavior without confirmed compromise.

## 2. Detection

The incident was detected by custom Wazuh rule `100102`.

The rule correlates three matches of custom rule `100101` within 120 seconds:

```xml
<rule id="100102" level="10" frequency="3" timeframe="120">
  <if_matched_sid>100101</if_matched_sid>
  <description>Custom Detection: Possible brute-force attack - 3 failed logins within 2 minutes</description>
  <group>windows,authentication_failed,bruteforce,custom_detection,</group>
</rule>
```

The underlying authentication event was Windows Event ID `4625`.

---

## 3. Initial Triage

The first step was to validate the alert and determine whether the authentication failures were isolated or repeated.

### Key observations

- Multiple failed logon events were generated within the configured two-minute window.
- The target account was `Madhusughand`.
- The logon type was `2`, indicating interactive authentication.
- The source address was `127.0.0.1`, which represents the local Windows host.
- The process associated with the event was the legitimate Windows `svchost.exe`.
- The Wazuh correlation rule correctly escalated the repeated activity to Level 10.

Because the source was localhost and the activity was generated intentionally in the lab, there was no evidence that the event represented an external attacker.

## 9. MITRE ATT&CK Mapping

### T1110 — Brute Force

The detection maps to:

**MITRE ATT&CK T1110 — Brute Force**

The mapping is based on repeated authentication failures that resemble brute-force behavior.

This does **not** establish that a real attacker successfully performed a brute-force attack. In this lab, the authentication failures were intentionally generated to validate the custom detection rule.

---

## 10. Incident Response Actions

### Identification

- Validated the Wazuh Level 10 alert.
- Confirmed the underlying Windows Event ID 4625 events.
- Identified the targeted account and authentication details.
- Confirmed that the correlation rule triggered after three matching events.

### Containment

No destructive containment action was required because:

- The activity was generated intentionally in the lab.
- The source was `127.0.0.1`.
- No confirmed compromise was identified.

In a production environment, continued suspicious activity against an administrator account could justify temporarily restricting or disabling the account according to organizational policy.

### Eradication

No eradication was required.

The investigation did not identify:

- Malware
- Malicious persistence
- Unauthorized accounts
- Suspicious executables
- Confirmed privilege escalation
- Confirmed unauthorized access

### Recovery

The endpoint remained operational.

Recommended production recovery/monitoring actions would include:

1. Continue monitoring failed authentication events.
2. Review successful logons (`4624`) following repeated failures.
3. Review privileged logons (`4672`).
4. Investigate the actual originating source if repeated activity continues.
5. Escalate if failed authentication is followed by successful unauthorized access.

---

## 11. Final Assessment

### Verdict

**Potential Brute Force / Suspicious Authentication Activity — No Confirmed Compromise**

The Wazuh detection successfully identified three failed authentication events within the configured two-minute threshold and generated a Level 10 alert.

The subsequent investigation did not identify evidence of compromise.

No malicious process, persistence mechanism, malicious network destination, unauthorized successful login, or privilege escalation was identified.

The alert is therefore best documented as **suspicious authentication activity with no confirmed compromise**, rather than a confirmed brute-force attack.
